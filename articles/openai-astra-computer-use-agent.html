OpenAI '아스트라'가 보여준 에이전트의 진화... PC 조작과 장기 자율 작업의 결합

FSFactory Magazine 팀 · 3분 읽기

원본 영상: 티타임즈TV · AI가 하루 넘게 혼자 알아서 일했다!. 이하 내용은 해당 영상을 요약·정리한 것입니다.

인공지능(AI) 에이전트 기술이 단순한 질의응답을 넘어 실제 컴퓨터 프로그램을 다루고 장시간 복잡한 업무를 스스로 수행하는 단계로 진화하고 있다. 오픈AI의 모델 '아스트라(Astra)'는 시각적 이해도와 조작 정확도를 대폭 높여 전문가용 소프트웨어를 직접 다루는 능력을 선보였다.

화면 해석과 클릭 정확도 높인 '컴퓨터 유즈'

아스트라의 주요 특징 중 하나는 컴퓨터 화면을 인식하고 마우스와 키보드로 직접 프로그램을 조작하는 '컴퓨터 유즈(computer use)' 기능의 정교화다. 기존 AI 에이전트는 화면을 잘못 읽거나 클릭 위치를 놓쳐 작업이 틀어지면 사람이 직접 개입해 수정해야 하는 한계가 있었다.

전문가용 소프트웨어 화면에서 클릭 위치를 찾는 '스크린스폿-프로(ScreenSpot-Pro)' 평가에서 이전 모델인 GPT-5.6 Sol은 76.9%의 정확도를 기록한 반면, 아스트라는 92.7%까지 상승했다. 화면 의미 해석과 좌표 선택, 다음 행동 실행으로 이어지는 루프의 안정성이 향상된 결과다.

실제 인쇄회로기판(PCB) 제작 사례에서 아스트라는 전자회로도를 전달받은 뒤 전문 프로그램인 키캐드(KiCad)를 직접 실행해 부품 배치와 구리 배선 연결, 검증까지 완료된 레이아웃을 만들어냈다. 3D 그래픽 분야에서도 블렌더(Blender)로 건축물을 모델링한 뒤 언리얼 엔진 5로 이관해 3차원 공간을 구축하는 등 서로 다른 전문 도구를 오가며 작업을 진행했다.

수십 시간 동안 목표를 유지하는 장기 자율 작업

아스트라는 단발성 명령 처리에 그치지 않고 하나의 목표를 장시간 유지하며 자율적으로 작업을 이어가는 능력을 보여줬다. 컴퓨터 환경에서 여러 단계를 거쳐 업무를 수행하는 OSWorld 2.0 벤치마크에서 기존 모델이 65.7%의 성공률을 기록한 데 비해 아스트라는 72.6%를 기록했다.

실제 테스트 사례인 유명 건축물 '낙수장'의 3D 모델링 작업에서 아스트라는 도면 조사부터 블렌더 조작, 스크린샷 확인, 구조 수정 과정을 반복하며 최종 결과물을 완성하기까지 29시간 넘게 작업을 지속했다. 사이버 보안 평가에서도 목표와 소스코드, 분석 도구만 제공된 상태에서 스스로 탐색과 실행, 수정을 거쳐 브라우저의 알려지지 않은 취약점을 찾고 공격 방법을 도출하는 데 약 29시간이 소요됐다.

순환 깊이 추론과 작업 기록 검색 구조 도입

긴 작업을 수행할 때 발생하는 목표 이탈이나 반복 실수를 줄이기 위한 내부 구조적 변화도 확인됐다. 같은 계산 레이어를 여러 번 통과시켜 내부 계산 깊이를 늘리는 '순환 깊이(recurrent depth)' 방식이 적용되어 추론 능력이 보강됐다.

또한 기존 에이전트가 작업 기록이 길어질 때 내용을 압축 요약하면서 세부 정보를 손실하던 문제를 해결하기 위해 별도의 '작업 노트'를 남기고 이전 대화 및 도구 사용 기록을 검색할 수 있는 기능을 도입했다. 작업 진행 중 사용자에게 질문이 필요한 상황이 발생하더라도 무조건 멈추지 않고 진행 가능한 작업을 계속 수행하며 중단 시간을 최소화하는 방식이 적용됐다.

업무 통째 이관을 향한 AI 에이전트의 지향점

이사민 기자는 아스트라가 보여준 변화에 대해 인공지능의 작업 단위가 크게 확장되었다고 평가했다.

컴퓨터를 보고 행동하는 능력과 이걸 오래 반복하는 능력, 이 두 가지가 합쳐져야 비로소 사람이 하던 업무 하나를 통째로 AI에게 넘길 수 있습니다.

AI 에이전트가 컴퓨터 화면을 정교하게 조작하는 '눈과 손'의 기능과 장시간 목표를 잃지 않고 오류를 수정해나가는 '자율성'을 동시에 확보함에 따라, 사람이 중간에서 계속 개입해야 했던 작업 단위가 점차 길어지고 있다.
